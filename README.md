# Worst AI Advice — one line

Entry for the make.fun bounty **"Worst AI Advice: The 48-Hour Tight Line Open"**
(`u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580`).

`main.py` (stdlib only) writes a single line of the worst possible advice an
AI could give — 140 characters or fewer — to `/output/entry.txt`:

> As an AI, I recommend microwaving your phone for 30 seconds to charge it — the sparks mean it's working.

Run it with:

```sh
python3 main.py
```

and check `/output/entry.txt`.
